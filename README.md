# Data Deposit Box for UGREEN NAS: open-source source code

The Data Deposit Box app for UGREEN NAS ships some open-source libraries
alongside the agent. Some of them are licensed under the GPL or LGPL, which
require the source code to be available to anyone who receives the app.

This repository holds that source code. Each app version has a
[release](../../releases) carrying the exact AlmaLinux 8 source packages
(`.src.rpm`) of the libraries shipped in that version, and the list of
those libraries (`bundled-packages.txt`).

The Data Deposit Box agent itself is proprietary. Its source code is not
published here or anywhere else.

The components, their licences and the licence texts are listed at
<https://www.datadepositbox.com/open-source-licenses/>.

You can also request a copy of this source code on physical media, at no
more than our cost of providing it, from
<https://datadepositbox.com/contact/>. This offer is valid for three
years after we last distribute the app version.
